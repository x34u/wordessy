# 🐾 Wordyssey: Wordi's English Odyssey

Featuring an interactive Overworld Map across 5 mystical floating islands, volumetric 2D platforming, an English Vocabulary Training Arena ("Soal Ujian"), and a Character Sheet guide — all built with Apple design aesthetics, San Francisco typography, and procedural Web Audio API synthesis.**

### 1. 🗺️ Interactive Overworld Map & 13 Unique Stages
- **5 Themed Floating Islands & 13 Handcrafted Levels:**
  1. **1. Basic:** Lush meadow archipelago
     - `1-1 Basic Meadow`: Introduction to Wordi, wide ledges & jumping practice.
     - `1-2 Spring Path`: Trampoline bounce pads launching Wordi into sky-high star rings!
     - `1-3 Windmill Hill`: Hillside staircase ascending toward rotating Dutch windmills.
  2. **2. Daily Life:** Warm sunset terracotta village & river canyon
     - `2-1 Village Square`: Terracotta rooftops with horizontally moving timber merchant carts.
     - `2-2 Timber Bridges`: Suspension river bridges with fragile crumbling planks that shake and fall!
     - `2-3 Sunset Valley`: Staggered narrow rock pillars, chasm ferries, and high-altitude chests.
  3. **3. Adventure:** Alpine fortress castle peaks
     - `3-1 Alpine Ridge`: Snowy mountain ledges with authentic slippery low-friction ice physics.
     - `3-2 Castle Sconces`: Stone fortress ramparts flanked by glowing red floor spike hazard pits.
     - `3-3 Citadel Ramparts`: Castle summit with vertical moving elevators carrying Wordi between watchtowers.
  4. **4. Future:** Cyber neon sky metropolis
     - `4-1 Neon Skyline`: High-speed cyber booster launch pads across holographic rooftops.
     - `4-2 Cyber Monorail`: High-speed moving monorail train cars shuttling across open digital voids.
     - `4-3 Quantum Spire`: Phase-shifting quantum blocks that materialize and dematerialize on a timer.
  5. **Final Stage: Star Palace**
     - `Final Stage`: Grand Neoclassical Star Palace with floating marble tiers and the **Word Titan Boss Battle**!
       - Crown of glowing ancient runes (`W-O-R-D`).
       - Boss shoots hostile aimed star runes and summons mini-slimes!
- **Interactive Level Nodes:** Click any unlocked stage on the map to review objectives and launch directly into gameplay.
- **Dynamic Scenery:** Animated water ripples, swimming ocean whale, and sailing ship.
- **Motto Banner:** *"One word at a time, you can go a long way!" 🐾*

### 2. 🎮 Difficulty System & Volumetric 2D Action Platformer
- **Apple HIG Difficulty Selector:** Choose your challenge level anytime from the Start modal or World Map node card:
  - **Casual (4 HP):** 4 Hearts, 2.4s invulnerability, 0.75x enemy speed, 16s quiz timer, 1.0x score multiplier.
  - **Normal (3 HP):** 3 Hearts, 1.6s invulnerability, standard enemy speed, 12s quiz timer, 1.25x score multiplier.
  - **Hero (2 HP • 2x PTS):** 2 Hearts, 1.0s invulnerability, 1.35x fast foes, 8s quiz timer, 2.0x double score multiplier!
- **Interactive Platform Mechanics:**
  - 🚀 **Trampoline Bounce Pads:** Launches Wordi high into the clouds with spring sound and star bursts.
  - ⚠️ **Hazard Spikes:** Sharp metallic teeth that deal contact damage and trigger screen shake.
  - ❄️ **Slippery Ice Surfaces:** Low-friction momentum gliding across frozen mountain slopes.
  - 🪵 **Crumbling Bridge Planks:** Vibrates for 0.8s when stepped on before collapsing into the abyss.
  - 🚡 **Moving Platforms & Monorails:** Horizontal and vertical carriers that transport Wordi smoothly.
  - 🔮 **Phase Quantum Blocks:** Holographic platforms that cycle between solid and phantom states.
- **3D Floating Cliffs & Suspension Bridges:** Multi-layered horizontal rock strata (`dirtLight`, `dirtDark`, `rockStrata`), lush overhanging grass turf, and realistic catenary suspension bridges.
- **Wordi's Combat Moves:** Jump and double jump across chasms, fire sonic golden star **Bark Blasts**, and collect power-ups (Holographic Shield, Triple Bark, Speed Dash, Star Magnet).
- **Mystery Word Chests:** Opens mid-stage vocabulary challenges granting **+500 points** and **Invincible Star Shields**.

## 🚀 How to Run Locally or Deploy to GitHub Pages

### Run Locally
Double-click `index.html` in your file explorer, or run:
```bash
# Using Python
python -m http.server 8000
```
Then visit `http://localhost:8000`.

### Deploy to GitHub Pages (3 Clicks)
1. Push the contents of this folder (`index.html`, `h5p/`, `h5p-connect.html`, `scripts/`, `.js`, `.css`) to your GitHub repository root:
   ```bash
   git add .
   git commit -m "feat: Wordyssey game with H5P Course Presentation for Lumi"
   git branch -M main
   git remote add origin https://github.com/your-username/wordyssey.git
   git push -u origin main
   ```
2. In GitHub, go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Live immediately at `https://your-username.github.io/wordyssey/` with zero asset or audio 404 errors!

## 🎓 H5P & Lumi Integration (School Project Setup)

This project includes ready-to-use `.h5p` packages under `h5p/` built with official H5P Hub libraries so you can connect the HTML5 game to **both Lumi Cloud (`app.lumi.education`) and Lumi Desktop** using **Game Map (`H5P.GameMap`)** + **Course Presentation** (not Tabs):

| Package / Tool | Purpose | Lumi Compatibility |
| :--- | :--- | :--- |
| `h5p/wordyssey-game-map.h5p` | **Primary deliverable:** Interactive 10-stage **`H5P.GameMap`** over Wordyssey's 5-island map (`world-map.png`) with **Course Presentation** stages (`H5P.CoursePresentation`, not Tabs), MultiChoice, Drag the Words, True/False, Memory Game, Dialog Cards, Single Choice Set, and direct HTML5 game launch links. | **Lumi Cloud + Lumi Desktop** |
| `h5p/wordyssey-course-presentation.h5p` | **Standalone Course Presentation:** 10-slide **`H5P.CoursePresentation`** with Wordi artwork, flashcards, quizzes, Summary score slide, and HTML5 game launch links. | **Lumi Cloud + Lumi Desktop** |
| `h5p/wordyssey-iframe-embed.h5p` | **Bonus IFrame Embed:** Wraps your live GitHub Pages game URL using official `H5P.IFrameEmbed` (`1.0.29`). | **Lumi Desktop / LMS** *(Note: use `--offline-html` in `build_h5p.py` only for servers allowing `.html` inside `content/`)* |
| `h5p-connect.html` | **1-Click GitHub → Lumi Connector:** Open on your live GitHub Pages site (`https://your-username.github.io/wordyssey/h5p-connect.html`) to automatically stamp your live game URL into `wordyssey-game-map.h5p` (or `wordyssey-course-presentation.h5p`) and download it. | Browser (no install needed) |
| `scripts/build_h5p.py` | CLI builder to regenerate all `.h5p` files with any custom `--url`. | Python 3 |

### Step-by-Step: Connect GitHub HTML5 Game into Lumi (Game Map + Course Presentation)
1. **Deploy to GitHub Pages** using the steps above so your game is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
2. **Generate your linked `.h5p`:**
   - **Option A (Easiest — in browser):** Visit `https://YOUR-USERNAME.github.io/YOUR-REPO/h5p-connect.html`. It auto-detects your live GitHub Pages URL — click **Download Game Map .h5p**.
   - **Option B (CLI):** Run:
     ```bash
     python scripts/build_h5p.py --url https://YOUR-USERNAME.github.io/YOUR-REPO/
     ```
   - **Option C (Inside Lumi):** Upload `h5p/wordyssey-game-map.h5p` directly into Lumi, click **Edit**, and update the Course Presentation Link elements / Final Stage external link to your GitHub Pages URL.
3. **Open / Upload in Lumi:**
   - **Lumi Cloud (`app.lumi.education`):** Upload `wordyssey-game-map.h5p` to your content library and publish/share.
   - **Lumi Desktop:** Open `wordyssey-game-map.h5p` directly via **File → Open**.

## What's new in v2

**New look (`theme.css`)**: an ink-and-sticker design system replaces the frosted-glass UI. Bricolage Grotesque + DM Mono type, a lime/orange palette on near-black, hard offset shadows, and buttons that physically press. Each world also gets a colour grade and vignette over the canvas.

**Gameplay (`enhance.js`)**: extends the existing classes in place.

| Addition | How it works |
| :--- | :--- |
| Coyote time + jump buffer | Jumps forgive early/late presses |
| Variable jump height | Release <kbd>W</kbd>/<kbd>Space</kbd> early for a short hop |
| **Stomp** | Land on slimes and bats to defeat them and bounce (porcupines are spiky) |
| **Dash** | <kbd>Shift</kbd> / <kbd>K</kbd>: brief invulnerability that cuts through foes; `»` button on touch |
| **Ground Pound** | <kbd>S</kbd> in mid-air: shockwave that hits nearby enemies and stuns the boss |
| **Combo chain** | Kills and stars within 2.6s stack a multiplier with floating score popups |
| Hit-stop and glow | Freeze-frame on kills, additive glow on pickups, dash afterimages |
| Boss upgrade | Enrages below 50% HP; defeating the Word Titan now wins the stage |
| Fair respawn | Pit falls return you to the last safe ground |
| Real pronunciation | Speech synthesis on the Pronounce button and on correct answers |

Google Fonts load from the web; offline, the theme falls back to system fonts.

**Pointer fixes**: stage hit-areas on the map are larger (nearest stage wins), the "Let's Go" callout is now a real button with a hand cursor and hover lift that launches the active stage, its tail no longer has a seam, and the playfield shows a crosshair since clicking fires a bark.
