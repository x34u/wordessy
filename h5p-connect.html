How to Submit for School (GitHub + Lumi)

  1. Upload to GitHub: Push all files inside this folder (index.html, h5p/, scripts/, etc.) to your GitHub repository, then enable Settings → Pages → Deploy from branch (main / root).
  2. Open this page on GitHub Pages: Visit https://<your-username>.github.io/<repo-name>/h5p-connect.html. Your live game URL is auto-detected!
  3. Download wordyssey-game-map.h5p: Click Download Game Map .h5p above so every Course Presentation link and the Final Stage map link point directly to your live GitHub game.
  4. Connect in Lumi: Upload wordyssey-game-map.h5p in Lumi Cloud (app.lumi.education) or open it in Lumi Desktop.
